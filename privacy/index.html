Privacy

Last updated 2026-09-16

This website

thehappylegend.com is a static site. It sets no cookies, runs no analytics and loads no third-party scripts. There is nothing to consent to, so there is no banner.

The site is served by GitHub Pages. Like every web server, GitHub may keep standard access logs (IP address, time, page requested) for security and operations. We do not have access to them and do not use them. GitHub’s handling of that data is described in GitHub’s privacy statement.

Email

If you write to contact@thehappylegend.com we keep your message for as long as it takes to answer it and for a reasonable time after, so we can follow up. We never add you to a list.
